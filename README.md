# Jaden Dunning Portfolio

A three-page static portfolio website:

- `index.html` — About
- `resume.html` — Resume
- `projects.html` — Projects
- `styles.css` — Shared styling

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `jaden-dunning-portfolio`.
2. Upload all four files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the site URL.
7. A custom domain can be added later under **Settings → Pages → Custom domain**.

The site intentionally uses no JavaScript framework or build step, so it can be hosted directly from the repository.
